# Elevate Events

Создай современный премиальный лендинг для агентства по организации корпоративов, тимбилдингов и взрослых дней рождения.

ВАЖНО:

Не используй детскую тематику.

Целевая аудитория: владельцы бизнеса, HR, руководители отделов, компании от 10 до 500 сотрудников, а также частные клиенты 25-55 лет.

Стиль: современный, премиальный, эмоциональный.

Дизайн уровня топовых event-агентств.

Использовать темную цветовую гамму с яркими акцентами (черный, графитовый, золотой, оранжевый).

Много крупных фото и видео-блоков.

Максимальный упор на эмоции, командный дух и впечатления.
